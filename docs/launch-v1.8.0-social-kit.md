# ContextVault Desktop v1.8.0 launch kit

## LinkedIn

ContextVault Desktop is no longer a thin CLI wrapper.

I rebuilt it as a full GUI product over the same local-first package engine: dedicated History, Decisions, Problems, Tasks, Retrieve, Search, and Prepare workflows; real filters; grouped results; copy/export; multi-project switching; and live `.contextvault` file watching.

You can record from Desktop, create a session from the npm CLI, and see both in the same app immediately. The raw command runner still exists, but only under Advanced CLI Mode.

No backend. No account. No telemetry. Markdown stays the source of truth.

## Reddit

Title: I turned my local-first AI context CLI into a full Desktop GUI

ContextVault stores AI and coding-agent context as local Markdown. The CLI already had recording, history, retrieval, prepared context, memory, links, and exports, but the first Desktop UI still expected users to understand command arguments. v1.8.0 replaces that with dedicated workflows and live vault watching while keeping the CLI as the shared engine.
